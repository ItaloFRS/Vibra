# General Code Style Guide

- **Clean Code:** Write small, single-purpose functions/methods.
- **DRY (Don't Repeat Yourself):** Extract reusable logic into utility functions ou serviços.
- **SOLID Principles:** Adhere to SOLID for object-oriented design (specially on Java Backend).
- **Formatting:** Use Prettier/ESLint (Frontend) and spotless/google-java-format (Backend).
- **Comments:** Comment the "why", not the "what". Code should be self-documenting.
