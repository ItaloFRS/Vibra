# Conductor Workflow

## Test-Driven Development (TDD)
- **Coverage Requirement:** >80% code coverage is required for all new features and bug fixes.
- **TDD Sequence:** Write failing tests -> Implement feature -> Verify tests pass -> Refactor.

## Version Control
- **Commit Frequency:** Commit changes after every completed task (Per Task).
- **Commit Message Format:** Use Conventional Commits (`feat:`, `fix:`, `chore:`, `test:`, etc.).
- **Summaries:** Include detailed task summaries in the commit message body.

## Phase Completion Verification and Checkpointing Protocol
- At the end of each phase, a verification step must be performed.
- All tests must pass before a phase is considered complete.
- Code style and linters must be verified.
