# HTML & CSS Code Style Guide

- **Semantic HTML:** Use semantic tags (`<header>`, `<main>`, `<article>`, `<section>`).
- **Tailwind CSS:** Utilize utility classes following the Design System tokens (como documentado no VIBRA).
- **Accessibility (a11y):** Always include `alt` tags on images, `aria-labels` where necessary, and ensure high contrast.
- **Responsiveness:** Mobile-first approach using Tailwind breakpoints.
